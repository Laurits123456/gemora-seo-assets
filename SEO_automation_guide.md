# SEO Automation Guide for Gemora

## 1. Keywords Everywhere API
- **Formål:** Hente søgevolumen, CPC og konkurrencedata direkte ind i applikationen.
- **Setup:**
  1. Gå til [Keywords Everywhere API Docs](https://keywordseverywhere.com/api-documentation.html).
  2. Tilmeld dig for en API-nøgle.
  3. Køb credits (starter fra $10 for 100.000 credits).
- **Prøvemuligheder:** Ingen direkte gratis API-prøve med volumen-data, men prisen er lav.

## 2. DataForSEO API
- **Formål:** Omfattende SEO-data inkl. SERP-tracking, backlink-analyser og Google Ads-data.
- **Setup:**
  1. Gå til [DataForSEO v3 Docs](https://docs.dataforseo.com/v3/).
  2. Opret en konto for at få adgang til dashboardet.
  3. Brug deres "Playground" til at teste endpoints.
- **Prøvemuligheder:** Tilbyder en "Free Unlimited Trial" for sandbox-miljøet, så man kan teste integrationen før betaling.

## Anbefalet Arkitektur
Brug DataForSEO til overordnet SERP-monitorering og Keywords Everywhere til hurtig udtrækning af søgeords-metrics i Gemora-platformen.
